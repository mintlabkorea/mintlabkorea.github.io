# Context-Continuous Preference Learning for Exoskeleton Personalization

This directory contains the source code for the project website for:

**Context-Continuous Preference Learning for Exoskeleton Personalization**  
Sunin Baek, Sungwoo Park, and Daekyum Kim

- arXiv: https://arxiv.org/abs/2609.28427
- PDF: https://arxiv.org/pdf/2609.28427

## Required figure files

Place the following figure images in `static/images/`:

- `fig1.png` — paper Fig. 1: preference-learning strategies across contexts
- `fig2.png` — paper Fig. 2: ankle/elbow exoskeleton experiments and contexts
- `fig5.png` — paper Fig. 5: human-study evaluation

The existing CSS, JavaScript, fonts/icons, and favicon from the LLJKE website template can be reused.
